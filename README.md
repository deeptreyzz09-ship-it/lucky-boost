# Lucky Boost

Telegram Mini App на HTML, CSS и JavaScript.

## Возможности

- Telegram WebApp SDK, BackButton и Haptic Feedback;
- адаптация под safe area мобильных устройств;
- сохранение языка и последнего промокода в `localStorage`;
- совместимое с Telegram WebView копирование;
- русский, английский и румынский интерфейс;
- готово к GitHub Pages.

## GitHub Pages

Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Сайт будет доступен по адресу:

https://deeptreyzz09-ship-it.github.io/lucky-boost/

## Важно

Текущие коды демонстрационные и генерируются в браузере. Для настоящих промокодов нужен backend.

Перед публикацией замените `https://example.com/register` в `index.html` на реальную ссылку регистрации.
